## このリポジトリは何をするところ？

**「ロボットの形と動かし方を同時に AI に決めさせる」** 研究のコードです。

普通のロボット AI は「形は人間が決めて、動かし方だけ AI が学ぶ」ですが、
このシステムは **形（腕の長さ・関節の強さ）も動かし方も、両方 AI が自動で最適化** します。

研究の目的は「手描きスケッチから、このロボット形態でこのタスクはできるか？をすぐ確かめる」システムの構築です。

## よく出てくる用語（最小限）

| 用語 | 意味 |
|---|---|
| **co-design** | 形と動かし方を同時に最適化すること |
| **Stackelberg PPO** | このシステムが使っている学習アルゴリズムの名前 |
| **Leader（リーダー）** | 形を決める AI（腕の長さや関節の強さを選ぶ） |
| **Follower（フォロワー）** | 動かし方を決める AI（関節にどの強さでトルクをかけるか） |
| **epoch / ep** | 学習の1サイクル。ep200 = 200回学習した状態 |
| **exec_R_eps** | タスクの成績（大きいほど良い）。グラフでこれを見る |
| **Pusher** | キューブを押して遠くに飛ばすタスク |
| **Reach** | アームの先端を目標点に届かせるタスク |
| **Target-Pusher** | キューブをちょうど目標位置に止めるタスク |
| **Choreonoid** | 使っている物理シミュレーターの名前（MuJoCo の代わり） |

## 最初にやること（環境確認）

```bash
# Dockerコンテナ内にいることを確認
pgrep -a choreonoid   # 学習中のプロセスがあれば表示される

# 学習の実行（Pusherタスクの例）
USE_CHOREONOID=1 OMP_NUM_THREADS=1 \
  choreonoid --no-window --python scripts/choreonoid_train.py \
  cfg=pusher num_threads=1

# 学習曲線の確認
python3 scripts/plot_rewards.py single_run/pusher_cnoid
```
