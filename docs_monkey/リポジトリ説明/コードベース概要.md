# コードベース概要（猿でもわかる版）

---

## コードの全体像

```
StackelbergPPO/
├── design_opt/     ← この研究固有のコード（ここが本体）
│   ├── train.py   ← 学習のスタート地点
│   ├── agents/    ← 学習ループ全体を管理
│   ├── envs/      ← タスク別の環境（pusher.py / reach.py など）
│   ├── models/    ← AI ネットワークの設計
│   └── utils/     ← 設定ファイル読み込み・Stackelberg 計算
│
├── khrylib/        ← 汎用 RL ライブラリ（原論文のコードをベースに改変）
│   └── robot/
│       └── xml_robot.py  ← ロボットの「形」をデータとして扱うクラス
│
├── scripts/        ← 学習・評価の起動スクリプト
├── design_opt/cfg/ ← タスク別の設定ファイル（YAML）
└── single_run/     ← 学習結果が保存されるフォルダ
```

---

## 学習を始めるには

```bash
# Pusher タスクで学習（基本コマンド）
USE_CHOREONOID=1 OMP_NUM_THREADS=1 \
  choreonoid --no-window --python scripts/choreonoid_train.py \
  cfg=pusher num_threads=1

# Reach タスクで学習
USE_CHOREONOID=1 OMP_NUM_THREADS=1 \
  choreonoid --no-window --python scripts/choreonoid_train.py \
  cfg=reach num_threads=1
```

**注意**: `python3 scripts/...` で起動すると物理シミュレーターが動きません。
必ず `choreonoid --no-window --python ...` で起動してください。

## 学習結果の保存場所

学習を実行すると `single_run/` の下にフォルダが作られます。

```
single_run/pusher_cnoid/
├── models/
│   ├── epoch_0010.p   ← 10 エポックごとのスナップショット
│   └── best.p         ← これまでの最高スコアを出したときの重み
├── log/
│   └── log_train.txt  ← エポックごとの数値ログ（テキスト）
└── .hydra/
    └── overrides.yaml ← 実行時の設定の記録（一次証拠！）
```

**`best.p`** が学習済みの AI です。評価・可視化でここを指定します。

**`overrides.yaml`** は「この実験がどんな設定で走ったか」の記録です。
あとから設定を確認するときは必ずここを見てください。

## 設定ファイルの仕組み

設定は YAML ファイルで管理します。

```
design_opt/conf/config.yaml    ← デフォルト設定（基本は触らない）
design_opt/cfg/pusher.yml      ← Pusher タスク専用の設定
design_opt/cfg/reach.yml       ← Reach タスク専用の設定
```

起動コマンドの `cfg=pusher` が「`pusher.yml` を読んで」という指示です。
設定を変えたいときはコマンドラインで上書きします：

```bash
# シードを変えて実行する例
... choreonoid_train.py cfg=pusher seed=1
```

---

## 重要なファイルだけ覚えれば十分

| ファイル | 役割 |
|---|---|
| `design_opt/train.py` | 学習ループのスタート地点 |
| `design_opt/agents/genesis_agent.py` | 学習全体を管理するメインクラス |
| `design_opt/envs/pusher.py` | Pusher タスクのルールと報酬計算 |
| `design_opt/utils/config.py` | 設定ファイルを読んで Python で使えるようにする |
| `scripts/choreonoid_train.py` | Choreonoid から train.py を呼び出す橋渡し |

## プロセスが残っていないか確認する

学習後にプロセスが残留することがあります。新しく実験する前に確認してください。

```bash
pgrep -a choreonoid    # 動いていれば行が表示される
pgrep -a python3       # 同上

# 止める必要があれば（止めていい学習かを必ず先に確認！）
pkill choreonoid
```
