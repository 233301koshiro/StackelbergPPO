# 評価スクリプト（猿でもわかる版）

---

## やりたいことから選ぶ

| やりたいこと | コマンド |
|---|---|
| 成績を数値で確認したい | `eval_cnoid_numerical.py` |
| 動作の動画を出したい | `eval_cnoid_visual.py` |
| GUI でリアルタイムに見たい | `eval_cnoid_viewer.py` |
| 学習曲線グラフを出したい | `plot_rewards.py` |

---

## 基本: 数値で成績確認

```bash
EVAL_RESTORE_DIR=single_run/pusher_cnoid EVAL_NUM_EPISODES=5 \
  USE_CHOREONOID=1 choreonoid --no-window --python scripts/eval_cnoid_numerical.py
```

- `EVAL_RESTORE_DIR`: 評価したい学習フォルダのパス（必須）
- `EVAL_NUM_EPISODES`: 何回試行するか（デフォルト 5）
- 出力: `single_run/pusher_cnoid/eval/eval_numerical.png`（棒グラフ）

---

## 動画を出力する

```bash
EVAL_RESTORE_DIR=single_run/pusher_cnoid \
  USE_CHOREONOID=1 choreonoid --no-window --python scripts/eval_cnoid_visual.py
```

**注意**: 実際の 3D 描画ではなく「関節位置を matplotlib でプロット」した簡易可視化です。
ロボットは青い点と線、cube はオレンジの点として表示されます。

出力先: `single_run/pusher_cnoid/videos/eval_visual.mp4`

## 学習曲線グラフ

```bash
python3 scripts/plot_rewards.py single_run/pusher_cnoid
```

出力先: `single_run/pusher_cnoid/plots/reward_plot.png`

複数 run を比較したいときはスペース区切りで渡せます：
```bash
python3 scripts/plot_rewards.py single_run/pusher_cnoid single_run/reach_cnoid
```

## 評価がどう動くか（仕組み）

学習時と同じく「設計フェーズ → 実行フェーズ」の順に動きます。
固定の形を読み込んで動かすのではなく、**毎エピソード AI が形を決めてから動かします。**

```
① 設計フェーズ（6 ステップ）
   AI リーダーがロボットの形を決める
   → ログが一気に流れる（Choreonoid 再ロード × 6）

② 実行フェーズ（最大 1000 ステップ）
   AI フォロワーがその形でタスクを解く
   → 指定 fps に合わせてゆっくり進む
```

## 出力ファイルの場所まとめ

```
single_run/{実験名}/
├── models/
│   └── best.p             ← 学習済み重み（ここを評価で使う）
├── eval/
│   └── eval_numerical.png ← eval_cnoid_numerical.py の出力
├── videos/
│   └── eval_visual.mp4    ← eval_cnoid_visual.py の出力
└── plots/
    └── reward_plot.png    ← plot_rewards.py の出力
```
