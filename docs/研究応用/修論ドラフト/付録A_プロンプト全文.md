# 付録A M1で使用したプロンプト全文

> **ドラフト管理**: 新設 2026-07-22。第3章 3.2節から本文を分離。

本付録は、第3章 3.2節「M1: 画像整形と関節マーカー規約」で述べた関節マーカー規約を、画像生成 AI（Gemini）に対する固定プロンプトとして課した際の全文である（3関節アームの例）。

```text
以下の仕様に従い、3関節ロボットアームを機械設計図スタイルで描いてください。

【形状・姿勢 — 最重要】
- 固定台座から垂直に伸びるシリアルチェーンアーム（根元が下・先端が上）
- リンク1（上腕）: 台座から伸びる中太の円柱カプセル
- リンク2（前腕）: 上腕より細く1.5倍長い円柱カプセル
- リンク3（先端）: 平たいパドル・へら形状

【関節マーカー — 最重要・省略厳禁】
すべての接続部に、純マゼンタ (#FF00FF) の球を1個ずつ描くこと。具体的には以下の3箇所:
1. 台座と上腕（赤）の間
2. 上腕（赤）と前腕（青）の間
3. 前腕（青）と先端パドル（緑）の間 ← ここも省略しないこと
- 3箇所すべて同じ様式（リンクより太いマゼンタの球）で統一すること。
  先端側の関節だけを金具・ヒンジ・ブラケット等の機械要素で描くのは禁止
- 描き終えたら、マゼンタの球がちょうど3個あることを確認すること

【色分け — グラデーション禁止・各色を単色で塗ること】
- ベース台座: 濃いグレー (#333333)
- リンク1（上腕）: 鮮明な赤 (#FF2222)
- リンク2（前腕）: 鮮明な青 (#2222FF)
- リンク3（先端パドル）: 鮮明な緑 (#22CC22)
- 関節球: 純マゼンタ (#FF00FF)
  ※ マゼンタはアーム本体色（赤・青・緑・グレー）には絶対に使わないこと（自動検出用のため）

【スタイル】
- 白背景
- CADソフトウェアのレンダリング風（プラスチック質感・影あり・幾何学的）
- 斜め45度視点（3/4アングル）、ロボット全体が収まる構図
```

初期版のプロンプトでは関節個数の誤描画（マゼンタ球が2個しか描かれない事例）が発生したが、上記の「関節マーカー」節にあるように関節位置を場所として明示的に列挙し、描画後の個数の自己検査を課す文言を追加したことで解消した。この改訂後のプロンプトでは、検証した生成事例において規約適合画像が初回の生成で得られている。

Gemini は Web インタフェース上で対話的に利用し、API 呼び出しによるサンプリングパラメータ（temperature 等）の指定は行っていない（第3章 3.8節、第5章 5.5.2節）。
