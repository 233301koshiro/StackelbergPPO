## 5.1 研究目的の達成

本研究は、ハードウェアの専門知識を持たない開発者が、手描きスケッチから出発してロボット形態のタスク適性をシミュレーション上で検証できる環境を構築することを目的とし、次の 3 つのリサーチクエスチョンを設定した。

1. **RQ1（システムの成立）**: スケッチに由来する形態について、モデル生成から適性判定、不適合であった場合の修正指針の提示までを、専門知識を要さない形で接続できるか
2. **RQ2（検証エンジンの妥当性）**: 中核に据えた形態-制御 co-design は、タスクの要求に照らして形態を正しく順序づけ、かつ実用的な学習量でそれを返すか
3. **RQ3（フィードバックの有用性）**: システムが返す修正指針は、設計のやり直しに実際に使えるか

⭐ **最大の結論は RQ1 に対するものである。**生成 AI が出力した三次元形状から、関節構造の自動抽出・モデル生成・co-design 学習の起動・適性判定・修正指針の提示までが一つのシステムとして接続された。設計者に要求されるのは形状の入力のみであり、関節可動域の定義、回転軸の指定、質量特性の算出といった機械工学の知識は要さない。⭐ **手描きの線画そのものを入力とする end-to-end の実走も 4 例を完了している。**

⚠️ **未達は、手描き入力の実走を API 経路で取り直していないこと**（実走は画像整形と三次元形状生成を対話的インタフェースで行った）**と、専門知識を持たない利用者を対象とした評価**である。いずれも 5.4 節の今後の課題に対応する。

## 5.2 主要な結論

### 5.2.1 スケッチから適性判定までを通すシステムが成立した

関節マーカー規約に基づく画像から、三次元形状生成・関節検出・リンク分割・モデル生成・学習起動・適性判定・修正指針の提示までが接続された（第3章、第4章 4.2〜4.5 節）。RQ1 に対しては、スケッチ由来の形態をシミュレーション上で評価するシステムを構築できたと結論づける。⚠️ ただし前段の生成は決定的ではなく、学習による比較には 4〜16 時間を要し、外部サービスの取得には人手が残る（4.2・4.5 節）。

### 5.2.2 判定に必要な入力は形態の中核要素のみである

**判定が要求する入力は、リンクの本数・長さの比・関節位置と関節軸の割り当てに限られる。**質量・材料・アクチュエータの型番・部材の断面形状は与えていない。それでもタスクによって最良形態の順位が入れ替わり（4.3.3.3 節）、幾何診断が同一の出力を返す形態対にも順序が付き（4.3.3.4 節）、三層診断の総合判定は 6 条件すべてで実測と一致した（4.4.1 節）。⭐ **したがって判定は線画を一枚描いた時点に置ける。**本手法の位置は「線画と精密設計の間」ではなく「線画の直後」であり、⚠️ 細部の動力学が判定にほとんど入らないことはその裏面である（5.3 節 (C)、5.4 節 7）。

### 5.2.3 検証エンジンはタスクに適した形態を識別する

タスク以外の条件をそろえた統制実験（3 タスク × 2 シード）で、収束形態は **Pusher が高ギア比・長リーチ・打撃的方策**、**Reach が低ギア比・内部解・サブミリ精度の静止保持**、**Target-Pusher が Pusher と同族の形態に停止と保持**の 3 型に分かれた（4.3.2 節）。識別は個別パラメータではなく機能量の水準で現れ、パイプライン由来の 3 関節アームと非平面 4 関節アームでも再現した（4.2 節、付録D）。⚠️ 各条件 2 シードであり、主張は初期的な一貫性の確認に留める（5.3 節 (A)）。

### 5.2.4 修正指針に従えば不適合は解消するが、その実行可能性は判定の正しさとは独立に壊れうる

診断が返した拡大倍率を適用しただけで、到達タスクの平均残存距離は 397 mm から 0.33 mm へ三桁改善した（2 シード、4.4.4 節）。⭐ **ただし助言の実行可能性は判定の正しさとは独立に壊れうる。**判定が 6 条件すべてで実測と一致していたにもかかわらず、助言に従った形態を同じ診断が再び却下し（倍率の丸め方向。4.4.3 節）、是正後には助言どおりに形態を生成する工程にも欠陥が見つかった（4.4.4 節）。いずれも助言を適用した形態を再入力する閉ループを構成して初めて現れた。⭐ **反実仮想的な助言を返すシステムは、出力の正しさとは別に、出力の実行可能性を検証する手順を持たなければならない。**

### 5.2.5 実在の部材とアクチュエータに基づく設計空間でも判定は成立する

設計空間の境界をアルミニウム薄肉パイプと協働ロボット（UR5e）の諸元から導き直すと、到達性能は 36 % 低下するが、**タスクによる形態の識別も、幾何が区別できない形態対の順序づけも成立し、識別の質はむしろ向上した**（4.6 節）。⭐ **本研究の結論は、根拠のない探索範囲に依存して得られたものではない。**⚠️ 接触係数だけは設計空間から制御できない（5.3 節 (C)）。

付随する知見として、warm-start による判定の高速化（付録D）と、固定根本アームへの co-design の移植で得た実験条件設計の 5 原則（報酬を単一項に保つ／PBRS の初期値に形態依存量を使わない／形態比較の前に幾何的整合を確認する／ペナルティは棄却ではなく勾配として与える／形態の良否は幾何・収束設計・行動の三層に分けて読む）を報告する。⚠️ いずれも本研究の貢献としては掲げない。

## 5.3 本研究の位置づけと限界

⭐ **本研究の成果はアルゴリズムの改良ではなく、これまで独立に発展してきた領域を結合した設計支援のシステムである。**スケッチからの形状生成、co-design、反実仮想説明に立脚した設計フィードバックはいずれも既存の研究領域に属し、本研究はこれらを**専門知識を持たない設計者が概念設計段階で使える一つのパイプラインとして接続した**（差分は 2.5 節 表 2.1）。⭐ **このシステムにおいて co-design は「最適形態を自動設計する手法」ではなく「形態のタスク適性を判定する検証エンジン」として用いられる。**

⚠️ **本研究のスコープはシミュレーション環境における初期判定に限定され、実機ハードウェアの構築と sim-to-real gap の解決はスコープ外である。**あわせて、本研究が用いる「妥当」の語は想定利用者が同じ語で意味するものと一致しない。本研究の「妥当」は**タスクを達成できるか**を指し、関節の実装可能性・部材の強度・組立可能性を含む**製作可能性は判定しない**。したがって本手法の出力は「このタスクに向く形態の候補」であって「製作してよい設計」ではない。⚠️ **この区別が影響するのは主張ではなく、判定を経た形態を製作へ引き渡せるという利用経路の完結性である。**

限界は次の 4 群に整理できる。

**(A) 検証の範囲と統計的信頼性。** 検証の中心は平面2関節の固定根本アームであり、3関節・非平面4関節への再現は確認したが（付録D）、非平面形態における識別の強弱は主張しない。全方向到達や移動型形態への一般化は範囲外である。各条件のシード数は 1〜2 で統計的検定を行っていないため、**本論文では「頑健」の語を用いず、主張は「シード間で初期的な一貫性が確認された」の水準に留める。**手描き入力から規約準拠のモデル生成まで到達した事例も 5 件であり、前段の頑健性を成功率として報告できる件数ではない。同じ理由から ablation の寄与率も百分率としては確定させず、主張は「リンク長の寄与がギア比の寄与を平均では上回る」という順序関係に限定される。

**(B) 入力側の制御可能性。** 判定対象の絶対的な大きさは生成モデルの出力に依存し、本手法から制御できない。一方タスク側の目標位置は絶対座標で与えられるため、**このスケール不整合は形態最適化では吸収できない。**本研究はこれをスコープ外と宣言し、不整合を検出して必要な拡大倍率を返す立場をとる（3.12 節）。また外部サービスは API 経由でパラメータを固定できるが（3.13 節）、⛔ **画像生成は低温設定でも出力が一意に定まらず、再現できるのは「後段が使う量の一致」までであって生成物の同一性ではない。**⛔ **4.5 節が報告する実走 5 件は API 実装前に取得したものである。**関節可動域とギア比の初期既定値、エンドエフェクタ向きの補正指定も人手の設定が残る。

**(C) 物理モデルの不完全性。** リンクはカプセル（円柱＋半球）で近似され、学習系が設計変数として扱える形はカプセルと球に限られる。傾いた腕を水平な面で分割するため半径は小さめに見積もられうる（B1 の手先で頂点の 70.9 % が外に出るが、はみ出し量の中央値は 5〜10 mm。3.9 節）。関節空間の慣性行列は **99 % 以上がアクチュエータの反射慣性（`armature`）で占められ**、リンク形状が寄与する割合は 0.01〜1.14 % に留まる。したがって本手法の形態最適化が確実に作用しているのは幾何であり、**動力学的に有利な形態を選べているとは主張しない。**また MuJoCo 互換 XML から Choreonoid への変換器は**接触に関する記述を一つも読み取らず**、学習側の実効的な反発係数は約 0.055 で、実在の金属・樹脂間で報告される 0.2〜0.5 を大きく下回る。さらに台座リンクの位置オフセットは運動学の連鎖に寄与しないため、**10 次元の設計空間のうち 2 次元には勾配が伝わらない。**⚠️ **設計空間の次元は是正が容易である**が、変更すると既存の全実験と探索範囲が異なり**比較可能性が失われる**ため是正していない。⛔⛔ **一方、接触条件は本研究が用いる物理エンジンでは設定する手段そのものが無い。**Choreonoid の AISTSimulator は材質ごとの反発係数を参照せず、ワールド全体の反発係数を設定する API も求解部から読まれない。⭐ **反発係数を設定するには物理エンジンを置き換える必要がある。**同梱の Bullet プラグインは反発係数を実装しており、置き換えは原理的には可能である。⛔ **しかし接触を扱うエンジンを替えると全条件の物理が変わり、既存の全実験との比較可能性が失われる。**⭐ **そこで本研究は、壁との接触を物理エンジンではなく速度反射としてモデル化した。**⚠️ **本研究の主張はタスク間・形態間の相対的な順序であり、全条件が同一の設定を共有するため順序の比較そのものは成立する。**

**(D) 判定の精度と費用。** 判定に要する学習量は、設計が明確に異なる候補で 30 エポック（約4時間）、拮抗する場合は 120 エポックであり、**対話的な設計支援が要求する「即時」の水準には達していない。**Target-Pusher の報酬は理論上限 0.5 に対し実測が 0.450 および 0.490 ＝ **上限の 90〜98 %** であり、**成功した形態どうしの優劣を分解する分解能を持たない**（順序づけには到達・押しタスクを用いる）。第2層・第3層の判定閾値は較正されていない。関節使用率の閾値（可動域の 10 %）について較正を試みたが、**閾値近傍の関節を固定した成績はシード間で向きが反転した**（+24.1 % と −34.1 %）。⭐ **ただし閾値が決めるのは固定を試す候補であって採用の可否ではなく、採用は成績範囲の重なりで判断するため、閾値が不正確でも誤った助言は採用されない。**⚠️ **防げないのは見落としであり、閾値が候補に挙げなかった助言が成績を改善した実例がある。**実在部材に基づく条件では使用率の最小が 14 % で第3層が助言を出さず、実測で最小の関節を直接固定しても成績範囲は可動側と重なった。⭐ **採否の手続きは実在条件でも設計どおり働いているが、第3層の閉ループが閉じたわけではない。**⭐ **第1層の助言は到達可能半径と目標距離という幾何のみで決まるため、密度・アクチュエータ出力・リンク長の設定に原理的に依存しない。**

## 5.4 今後の課題

1. **前段の再現性と入力の一般性**: 前段の 2 工程は API 経由の呼び出しを実装し、パラメータを固定できる状態にしたが、報告した実走 5 件はそれ以前に取得したものであり、実走数自体も少ない。API 経路での取り直しと生成サービスの版管理を進め、関節数や入力構図の異なる線画で、関節検出からモデル生成までの成立条件を評価する。
2. **形態・タスク・判定性能の一般性**: 非平面形態ではタスク別の分岐を確認したが、モデルはパイプライン出力ではなく、リンク長の探索範囲にも限界がある。関節配置の偏りなど未検証の形態軸、配分のタスク依存性、立体・移動型形態への拡張を調べる。あわせてシード数を増やし、順位反転と非平面形態の主張を強化する。候補間の差に応じた停止則や、より強力な warm-start による高速化も課題である。
3. **設計空間を実在部材の組み合わせへ離散化する（最も優先度が高い）**: 本研究は設計空間の境界を実在部材とアクチュエータの諸元から導き直したが（4.6 節）、**空間そのものは連続のままである。したがって得られた形態が実在の部品で組み立てられる保証はない。**関節種別・部材強度・組立可能性を判定しない以上（5.3 節 (A)）、出力は「このタスクに向く形態の候補」に留まり、「製作してよい設計」には届かない。
   **この距離を埋める直接的な道筋は、設計空間を連続な数値範囲から実在部品の組み合わせへ置き換えることである。**部品ライブラリに基づく組立システム（RobotAssembler 等）は、各部品に質量・慣性・関節軸・可動域・トルク上限を属性として持ち、接続規則を満たす組み合わせのみを生成する。**この空間の上で探索すれば、得られた形態は定義上かならず製作可能である。**本研究が用いるシミュレータと同じモデル形式を出力する実装も存在するため、接続は現実的である。
   ⚠️ **ただし設計空間が連続から離散へ変わるため、本研究が用いた勾配に基づく形態最適化はそのままでは適用できず、組み合わせ最適化としての定式化を要する。**この点は基盤手法の枠組みを超えるため、本研究では扱わない。
4. **診断の拡張**: 現在の診断は固定閾値に依存し、第1層以外では判定を覆す最小変更を直接求められない。閾値の較正、関節軸・形態変数に対する反実仮想的な助言、およびLLMを含む診断方式の比較を行う。
5. **関節軸の推定**: 関節軸は関節ごとに指定でき、候補の列挙と第1層診断の組み合わせによって学習前に約半数を棄却できる（第3章 3.10 節）。しかし**軸そのものを入力形状から推定する処理は無く**、最終的な割り当ては利用者が候補から選ぶ。線画やメッシュの形状特徴から軸を推定する手法、および枝刈りの妥当性（棄却された配置が実際に到達不能であること）の実験的確認が課題である。
