## 0. 一言でいうと

**テキスト（1〜3 語）から、実際に歩く 4 本脚のロボットを 1 日で作る仕組み。**
text-to-3D のモデル（Meshy）で見た目のメッシュを作り、断面の太さから関節を置いて動くモデルにし、進化計算（外側）と強化学習（内側）で形と歩き方を同時に良くし、3D プリンタで作る。
主張の芯は「**生成モデルが作った形は、進化計算の出発点としてずっと強い**」（p.1 の I 節の key insight）。

## 4. 自分の研究（このリポジトリ）とのつながり

修論では 2.1 と 2.5 で引いている（参考文献 31、想定問答 Q55）。**流れの構成がいちばん近い研究**なので、輪講がそのまま審査の備えになる。

| 観点 | Text2Robot | この研究 |
|---|---|---|
| 入力 | テキスト 1〜3 語 → Meshy | 手描きスケッチ → Gemini で整形（M1）→ Tripo3D（M2） |
| 関節の決め方 | 断面積の発見則。「4 本脚 × 2 関節」の型が前提。メッシュは人が選ぶ | 入力側の色マーカーで指定し、取り出しに失敗したら止まる（M3、修論 2.2・第3章） |
| 形の扱い | 進化で形を作り替えて、より良い形を出す | 入れた形の適否を判定する（リンク長とギア比は co-design の中で動くが、出力は入れた形への判定・理由・直し方） |
| 制御の学習 | PPO（IsaacGym）、歩行 | Stackelberg PPO（Choreonoid）、押し・到達・打ち込みなどの操作タスク |
| 物理 | 実機の部品（サーボ・電池の箱）を形に組み込む | 実在の値（UR5e・アルミのパイプ。修論 4.1）。部品で組む方向は軸6（RobotAssembler） |
| 設計者に返すもの | 最適化した形 | 適否・理由・直し方（「腕全体を N 倍に」、修論 3.12・4.5.4） |

**共通点（話の山にできる）**
- **内側のループの考え方が同じ。**「形を固定して制御を学習させ、得た報酬でその形の力を測る」（p.3: "to assess a robot's capacity for acquiring a walking policy"）。この研究はこれを判定器として使い、Text2Robot は進化の適応度として使う。
- **タスクの要求が形に出る。**速度か省エネか、平地か荒れ地かで残る形が分かれる（図 8・9）。修論の R2（タスクを変えると収束する形が分かれる、4.2.1）と同じ型の結果。
- **学習量を固定した評価の問題を両方が持つ**（§3 の 4）。この研究は判定に要る学習量を較正している（R4、修論 4.6）。輪講で「Text2Robot の 2.46×10⁷ step はどう決めたのか」は自分にも返ってくる問いなので、答えを用意しておく。

**違い（言い方）**: 「生成した形から co-design までつなぐことは Text2Robot が先にやっている。この研究は、機械の知識は無いが作りたい形の概形を持つ人が描いた形を出発点に、適否と、合わない理由と直し方を返す側。Text2Robot は 1〜3 語のテキストから、形の概形まで生成モデルと進化に任せる側」（2026-11-02、ユーザー「入力がテキストなのと概形なこと」。想定問答 Q55）。⚠️ 「形を変えずに判定する」とは言わない（co-design はリンクの寸法とギア比を動かす）。著者も、報酬からメッシュの生成へ返す仕組みを今後の課題に挙げている（p.6）。⚠️ **「つなげたのはこの研究が初めて」とは言わない**（想定問答 Q55）。

**型（どちらにもある）**（2026-11-04、ユーザー「…は既存の現実にあるロボット？」→ 原文で確かめた）
- 「…に似た四脚歩行ロボット」の「…」は**既存のロボットではない**。試した 16 語は動物（Ant・Dog・Frog など 12）と物（Bread・Can・Corn・Shoe）で、ロボットの名前は無い（p.4 の図 5A・IV-A）。
- ただし**型ありき**: 文型が「四脚・歩行・ロボット」を決め打ちし、関節は「自然の四足動物に着想を得て、脚 4 本・各脚 2 関節」と仮定し（p.2 の III-B）、モーターは 8 個（III-A）、脚 4 本でないメッシュは人が落とす。ユーザーの語が決めるのは型にかぶせる見た目（胴の形・脚の比率・足の形）で、関節の位置は断面積の発見則が決める。
- **この研究にも型がある**: 根元を固定した直列の腕（子を親の先端に付ける入れ子、修論 3 章の M5）。上流（M1〜M3）を 3 関節以外で通した例は無く、縦型は根元に旋回を 1 つ足して 4 関節（同）。関節の軸はモードと関節ごとの指定で与え、形からは推定しない（知見総括表 G 節 ①）。M1 は Gemini で絵を描き直す。

| | Text2Robot | この研究 |
|---|---|---|
| 型 | 四脚・各脚 2 関節・8 モーター | 根元固定の直列の腕（試したのは 3 関節と縦型の 4 関節） |
| 型の中でユーザーが決めるもの | 見た目だけ（1〜3 語） | **関節の位置とリンクの比率**（絵とマーカー） |
| 型の中でシステムが決めるもの | 関節の位置（断面積の発見則） | 関節の軸（モードで決め打ち） |

**強化学習の違い**（2026-11-04、ユーザー「8 個も関節があったり、軸も設計空間に入れれる以上こっちのほうが優秀？」→ 原文 p.3〜4 とリポジトリで確かめた）
- Text2Robot の強化学習は**普通の PPO**（[62]、IsaacGym の並列学習 [63, 64] に従う）。方策と価値は全結合 3 層 [512, 256, 128]・ELU。観測は前の行動・胴の速度と角速度・関節の角度と速度・重力の向き・速度の指令。行動は関節の目標角度のずれで、PD でトルクにする（p.3 の III-C、p.4）。**形は観測に入っていない。**
- **形を動かすのは強化学習ではなく進化計算。**関節の軸（x・y・z の 3 択）も脚の長さも、変異の遺伝子（p.4）。8 関節は「方策が出す行動の数」であって、強化学習の手法の強さではない（12 関節の四脚を数分で歩かせるのが [64] の系統の標準）。
- 論文外（リポジトリ 1203e87）: 学習は rl_games 形式の設定（`LeggedTerrainPPO.yaml`: horizon 24・mini_epochs 5・γ 0.99・lr 3e-4 を適応で変える）。学習の起動に親の checkpoint を渡す箇所は見当たらず、**子は親の方策を引き継がずに毎回ゼロから学習する**と読める。適応度は学習中に保存した checkpoint のうち**報酬が最大のもの**（`greatest_reward.py`。最後の値ではない）。seed の既定は 42（`config.yaml`）。⚠️ 引き継ぎが無いことは、コードに無いことからの推測。
- この研究: Leader（形を編集する方策）と Follower（制御）の 2 つの方策を 1 回の学習で同時に更新する。Follower は形の設計パラメータを観測に含み、形に条件づけられる（修論 第3章前段）。設計変数は連続量（ギア比・太さ・後方延長・縦型は骨のベクトル、表 4.1）。トポロジーは固定（骨格変換は無効化）。
- **どちらが優れているか、とは比べない。**解いている問題が違う。Text2Robot は「形ごとに独立に学習 → 報酬で選ぶ」で、離散の選択（軸・部品）を扱いやすく、GPU で 1 体数分なので数を回せる。代わりに形の数だけ学習が要り、形の探索は無作為の変異。この研究は形と制御を 1 回の学習の中で一緒に動かし、連続量を勾配で動かす。離散の選択（軸・リンク数）は今は扱っていない。⚠️ 「1 体ずつ学習して報酬で比べる」は、この研究の形態比較（学習曲線の順位で判定、修論 3 章 M6・4.2.2）と同じ形なので、「Text2Robot は評価が粗い」とは突かない（§3 の 4 は自分にも返る）。

⭐ 差の芯は「型が無いこと」ではなく、**「型の中で関節をどこに置くかをユーザーが決められること」**（上の「違い」の概形の話と同じ線）。⚠️ **「絵を描くので既存の制約が無い」とは言わない**。型の狭さ（腕だけ）は修論 5.3 の 4 の限界で、「Text2Robot は四脚だけ」と突くと「あなたは腕だけ」と返る。型の広さでは比べない（想定問答 Q55）。

### 規則

1. **文字は黒。** 本文も見出しも黒（DARK1）。灰色（テーマの DARK2 #595959）は薄くて読みにくい。新しく作った文字の箱は DARK2 になるので、作ったら黒に直す
2. **対になる 2 つの役割に 1 色ずつ割り当て、全スライドで同じ語には同じ色を付ける。** 形・形態 = 青、制御・歩き方 = 緑。見出し・本文中の語・表の見出し・吹き出しの枠まで同じ色にする。色で「どちらの側の話か」が先に伝わる
3. **赤は「そのスライドで一番言いたいこと」だけ。** 1 枚に 1〜2 か所。主張・主結果の数値・注意点。赤が多いと、どれも強調されていないのと同じになる
4. **図の凡例と同じ色を本文の語に付ける。** 図を見なくても、本文のどの語が図のどの点・線かが分かる
5. **色は語の単位で付ける。** 文全体を塗らない（例外は赤で強調する主張の 1 文）
6. **1 つの色に 2 つの意味を持たせない。** 秋田2 は ACCENT1（青）を「リーダー」と「先行研究」の両方に使っていた。今回は避けた
