# スライドの作り方 — 過去の自分のスライドから抜き出した型

> 2026-11-02 作成（ユーザー「この言語化はスライドを作るときに役立つから抽象化してどこかに書けないか。構成やレイアウトも言語化して抽象化してほしい」）。
> **出どころ**: Google ドライブの自分の輪講スライド 2 つを API で読み、要素の位置・大きさ・文字の色と太さ・並び順を取り出して共通の型にした。
> - **秋田1**: 「輪講_秋田」（Learning Robot Structure and Motion Embeddings using GNN、26 枚、2025）
> - **秋田2**: 「輪講_秋田2」（Stackelberg PPO、20 枚、2026）
> - **秋田3**: 「輪講_秋田3」（Text2Robot、15 枚、2026-11-02）。この文書の規則で作り、ユーザーの直し（文字は黒・1 行に 1 項目）を反映した
>
> 各規則の右に、どのスライドから取ったかを書いた。**「自分のスライドで実際にやっていたこと」と「今回の指摘で決めたこと」を区別している。**
> 具体的な当てはめの例は [輪講_Text2Robot_素材.md](輪講_Text2Robot_素材.md) §6（色をどの語に付けたかの一覧）。発表の中身の作り方（白紙テスト → 主張を並べる → スライド）は [勉強.md](勉強.md) 第 2 部・第 4 部。

---

## 0. 一言でいうと

**「問題 → 目的・手法・検証 → 仕組み → 実験 → まとめ → 自分の研究への知見」の順に、1 枚 1 話題で並べる。各スライドは「太字の見出し＋短い説明」と図 1 つでできていて、色は「役割の色」「一番言いたいことの赤」「図と同じ色」の 3 種類だけを使う。**

## 1. 構成（スライドを並べる順番）

### 1.1 骨組み

秋田1・秋田2・秋田3 は、題材が違っても同じ順に並んでいる。

| # | 段 | 中身 | 枚数の目安（20 分） | 出どころ |
|---|---|---|---|---|
| 1 | 表紙 | 論文の題・著者・会場と年 | 1 | 3 つとも |
| 2 | 背景 → 問題 | 分野の流れを 2〜3 行 → **↓矢印** → 「問題」（または「課題」）の一文 | 1 | 秋田1 の 2 枚目・秋田2 の 2 枚目 |
| 3 | 概要 | **目的／手法／検証方法** の 3 見出し。この 1 枚で論文全体が分かる | 1 | 3 つとも（見出しの語まで同じ） |
| 4 | 前提知識 | 聞き手が知らない道具を 1 枚で（「GNN の概要」「強化学習のかんたんな説明」） | 0〜1 | 秋田1 の 4 枚目・秋田2 の 8 枚目 |
| 5 | 従来手法・関連研究 | 何がまだできていないか。最後に「→ 本研究は〜」 | 1 | 秋田1 の 5 枚目・秋田2 の 4 枚目 |
| 6 | 提案手法 | 全体像 1 枚 → 部品ごとに 1 枚ずつ | 3〜6 | 3 つとも |
| 7 | 実験 | 「この実験で示したいこと」→ 実験ごとに 1 枚 | 3〜6 | 3 つとも |
| 8 | まとめ | **問題／提案／結果**（または 概要／結果／今後の展望）の 3 見出し | 1 | 3 つとも |
| 9 | 限界・課題 | 著者が挙げた限界と、自分が読んで気になった点 | 1 | 秋田2「現在の課題」・秋田3「限界と疑問点」 |
| 10 | 自分の研究への知見 | 活かし方・違い・そのために必要なこと | 1 | 秋田1「得られた知見」・秋田2・秋田3「研究への知見」 |
| 11 | 付録 | 質問に備えた詳細（ネットワーク・データの定義・タスクの詳細） | 任意 | 秋田2 の 15〜17・19 枚目 |

### 1.2 並べ方の規則

1. **概要（3 枚目）を早く出す。** 背景の次にすぐ「目的・手法・検証方法」を置く。聞き手はここで全体の地図を持ち、以降の細部をその地図に当てはめて聞く（3 つとも 3 枚目）
2. **前提知識は、それを使う直前に 1 枚だけ挟む。** 冒頭にまとめない（秋田1 は提案手法の前、秋田2 は報酬の説明の前）
3. **章が長いときは、章の頭に目次のスライドを置き、各スライドの題に番号を付ける**（秋田1:「3章:提案手法」に 3-a〜3-c を列挙し、各スライドの題を「3-a:…」にした。秋田2・3 は枚数が少ないので省いた）
4. **まとめは概要と同じ形にする。** 概要の「目的／手法／検証」に対し、まとめは「問題／提案／結果」。冒頭で張った地図を、最後に結果で埋め直す
5. **最後は必ず自分の研究につなぐ。** 輪講でも「この論文から自分の研究に何を持ち帰るか」で終わる（3 つとも）
6. **質問に備える詳細は、まとめより後ろの付録に置く。** 本編の流れを止めない（秋田2）
7. **時間は 1 枚 1〜2 分。** 20 分なら本編 13〜16 枚。山場（手法の核・主結果）に 2〜2.5 分を割き、表紙・製作の詳細のような枚は 30 秒〜1 分で流す（秋田3 の発表原稿）

## 2. スライドの型（レイアウト）

### 2.1 共通の枠

ページは 10 × 5.625 インチ（16:9）。3 つとも同じテーマで、次の位置が決まっている。

| 要素 | 位置（インチ） | 書き方 |
|---|---|---|
| 題 | 上から 0.5、高さ 0.6、幅いっぱい（左寄せ） | 短い見出し（§3.1） |
| 本文の開始 | 上から 1.1〜1.3 | 題のすぐ下から |
| 左右の余白 | 0.3 | 図はこれより外へ出してもよい（秋田1 の図は左端 0.1） |
| 下端 | 5.3 まで | ページ番号（右下）にかぶせない |

### 2.2 よく使う型（6 つ）

| 型 | 配置 | 使う場面 | 出どころ |
|---|---|---|---|
| **A. 見出しの組** | 本文だけ。「**太字の見出し**＋改行＋説明」を 2〜4 組、上から積む | 概要・まとめ・限界・知見 | 3 つとも |
| **B. 問題の提示** | 上に背景の本文 → 中央に**↓矢印** → 下に「問題」の札（太字 20pt）と結論の一文（太字 20pt、幅いっぱい） | 背景 | 秋田1・秋田2 の 2 枚目 |
| **C. 本文の下に図** | 上 1/3 に「何を見るか」の 1〜2 行 → 下 2/3 に図（幅 6〜9 インチ、中央）→ 図の真下にキャプション 1 行 | 仕組みの説明・結果の図が横長のとき | 秋田1 の 4・12・19・22 枚目 |
| **D. 図と読み取りの左右** | 左に図（幅 4.5〜5.5）、右に読み取り（幅 4〜4.5）。読み取りは (a)(b)… と図の記号に合わせる | 実験の結果 | 秋田1 の 16・17 枚目・秋田3 の 9〜12 枚目 |
| **E. 図を並べて比べる** | 同じ大きさの図を横に 2〜4 枚、それぞれの真下に短いラベル（「親→子のみ」「2 往復」） | 条件を変えた比較 | 秋田1 の 24 枚目・秋田2 の 11 枚目 |
| **F. 擬人化の対比** | 2 つの役割を人物や AI の絵で左右に置き、それぞれに雲形の吹き出しで「考えていること」を書く。間に→ | 手法の核が 2 者の関係のとき | 秋田2 の 5 枚目（先手「ここに関節を 1 つ増やせば後手はこう適応してうまく動くはず…」） |

### 2.3 型の選び方

- **主張だけで図が無い → A。** ただし A が 3 枚続いたら、どれかを図にできないか考える
- **図があり、図が主役 → C か D。** 図が横長なら C、縦長か正方形なら D
- **条件を変えて比べる → E。** 図の大きさと縦の位置をそろえる。そろっていないと差が大きさの差に見える
- **2 者の関係が核 → F。** 数式より先に「どちらが何を考えているか」を見せる

## 3. 文字

### 3.1 題

- **短い見出しにする**（「背景」「本論文の概要」「実験結果」「まとめ」「研究への知見」）。輪講の 3 つはすべてこの書き方（3 つとも）
- 部品の説明のスライドは「何の話か」を題に入れる（「提案システム（ネットワーク）」「段 2：メッシュを動くモデルに変える」）
- ⚠️ **自分の研究の発表（予備審査・最終発表）では、主張の文をそのまま題にする**と [勉強.md](勉強.md) 第 2 部の 6 で決めている。輪講（他人の論文の解説）と審査の発表とで題の書き方が違う。どちらに寄せるかは発表の種類で決める

### 3.2 本文

| 規則 | 中身 | 出どころ |
|---|---|---|
| 見出し＋説明 | 「**太字の見出し**」の次の行に説明。見出しは 18〜20pt の太字、説明は 15〜17pt | 3 つとも |
| 1 行に 1 項目 | 列挙は 1 行に 1 つ。2 つを 1 行に詰めない | 秋田3 でユーザーが直した（4 枚目の ①〜④ を 1 行ずつに） |
| 矢印で「だから」 | 本文の中の「→」「⇒」は、前の文から導いた結論・自分の解釈を示す（「→本研究でも複数タスクとして FK と IK を用いる」） | 秋田1・秋田2 |
| 専門語に言い換え | 専門語の後に日常語を添える（「リーダー（先手）」「体を作る AI」「動かす AI」）。題でも「強化学習のかんたんな説明」 | 秋田2 |
| 原文をそのまま引く | 論文の弱点や著者の言い訳を述べるときは、英語の原文をそのまま引いてから自分の読みを書く | 秋田1 の 18 枚目 |
| 図から読んだ値は断る | 本文に無く図の目盛りから読んだ数値は「（図から）」と書き、細かい桁を言わない | 秋田3 |
| 文字の大きさ | 題はテーマのまま。本文 15〜18pt、図のキャプション 18pt（秋田1）、吹き出し 14pt。14pt より小さくしない | 3 つとも |

### 3.3 文字の色は黒

- **本文・見出し・キャプション・表は黒（テーマの DARK1）にする。** 灰色は薄くて読みにくい（2026-11-02、ユーザー指摘）
- ⚠️ このテーマでは、新しく作った文字の箱が灰色（DARK2 #595959）になる。**作ったら黒に直す。** 秋田1 のキャプションは灰色だったが、今後は黒にそろえる

## 4. 色（規則は 4 つだけ）

秋田2 の色を読み出し、秋田3 で当てはめた規則。

| # | 規則 | 秋田2 での例 |
|---|---|---|
| ① | **対になる役割に 1 色ずつ割り当て、全スライドで同じ語には同じ色を付ける。**本文の語・表の見出し・吹き出しの枠まで同じ色 | 形態・リーダー＝青 #4A86E8、制御・フォロワー＝緑 #6AA84F |
| ② | **赤 #FF0000 は、そのスライドで一番言いたいことだけ。**1 枚に 1〜2 か所。主張・主結果の数値・注意点 | 「+20.66 %」「学習のさせ方」「提案手法」 |
| ③ | **図の凡例と同じ色を本文の語に付ける。**本文のどの語が図のどの線・点かが、図を見なくても分かる | 「（グラフ青：平均で +20.66 %）」を線と同じ青に |
| ④ | **1 つの色に 2 つの意味を持たせない。**役割の青を「先行研究」にも使わない | 秋田2 は青を「リーダー」と「先行研究」の両方に使っていた。秋田3 で直した |

補足:
- **色は語の単位で付ける。** 文全体を塗らない（例外は、赤で強調する主張の 1 文）
- **論文名・データセット・ツールの名前**はテーマのリンクの色にしていた（秋田1 の「Open AI Gym」、秋田2 の「BodyGen」「Transform2Act」、表紙の論文の題）
- **白地で読めない図の色は暗くする。** 図の黄色の点はそのままだと文字にできないので、同じ色相で暗くする（秋田3 の RoboGrammar：#F4D966 → #B8860B）
- **役割の色を決める手順**: ① 論文の核にある「対になる 2 つ」を探す（形態と制御、先手と後手、提案と比較相手）② 青と緑を割り当てる ③ 論文の図に既に色があれば、そちらに合わせる（③ を優先）

## 5. 図・矢印・吹き出し

| 規則 | 中身 | 出どころ |
|---|---|---|
| 図は 1 枚に 1〜2 つ | 3 つ以上並べるのは型 E（比べる）のときだけ | 3 つとも |
| 図の下に 1 行の説明 | 図の真下、図と同じ幅で「何の図か」を 1 行（18pt） | 秋田1 |
| 図は論文から切り出す | 論文の PDF から図だけを切り出して貼る（キャプションの文は入れない）。縦横比を変えない | 秋田1〜3 |
| 図の一部に吹き出し | 図の中の注目点に、角のある吹き出し（14pt）で短い注釈を付ける（「グラフとしての形状は同じ」「今回は 2 次元のため pos_x,y のみ」） | 秋田1 の 7・10 枚目 |
| 矢印は 2 種類だけ | **↓**＝背景から問題を導く（型 B）。**→**＝図から結論・次の段へ（「→ この仕組みを両方の学習の土台として採用」）。飾りに使わない | 秋田1・秋田2 |
| 雲形の吹き出しは「考え」 | 人物・AI が考えていることを書く（型 F）。枠の色はその役割の色（§4 の①） | 秋田2 |

## 6. 作る手順（Google スライド）

1. **前回の輪講スライドをコピーして始める**（「輪講_秋田2」→「輪講_秋田3」）。テーマ・題の位置・文字の大きさを引き継ぐ
2. **表紙と骨組み（§1.1）の題だけを先に全部入れる。** 題だけを上から読んで話がつながるかを確かめる
3. **概要（3 枚目）とまとめを先に書く。** この 2 枚が対応していれば、間の枚は埋めるだけになる
4. **各スライドの型を §2.2 から選び、本文を書く**
5. **図を論文から切り出して貼る**
6. **色を付ける**（§4。役割の色 → 赤 → 図と同じ色の順）
7. **発表原稿を書き、発表者ノートに入れる**（1 枚ずつ、【目安の時刻】付き。前例は [輪講_Text2Robot_発表原稿.md](輪講_Text2Robot_発表原稿.md)）
8. **PDF に書き出して全枚を目で見る**: 文字が灰色のまま残っていないか、文字が箱からはみ出していないか、赤が 1 枚に 3 か所以上になっていないか

## 7. まだ決めていないこと

- 予備審査・最終発表（自分の研究）のスライドにも、この型をそのまま使うか。題の書き方（§3.1）のほかに、結果のスライドの型（帯つきの表・図）を足す必要がある
- 秋田1 は章番号つきの題（「3-a:…」）、秋田2・3 は番号なし。20 枚を超えるときだけ番号を付ける、で足りるか
