## スライド9: 現在の進捗 ⭐（2:30）

**構成: フローの図に進捗を重ねて、詰まっている所と抜けた所を色分けする。**

### ① 前段（M1〜M5）— 手描きが通るようになった

| | 結果 |
|---|---|
| 手描きスケッチからモデル生成まで | **5 例通った**（A1・A2・B1・B2・ホッケー） |
| 関節検出 | **5 例とも 3/3 自動検出** |
| 落ちた例 | **1 例**（斜め 45 度で描いた 1 枚。2 回試して 2 回とも） |

**落ちた理由まで言う**: 三次元化サービスが斜めの線を「奥行き」と解釈して**腕が寝る**。
リンク分割は**関節の高さを境界に切る**ので、寝ると原理的に分割できない。
→ **前段は入力の視点に依存する**という限界として報告できる。

> 話し方: **失敗を隠さない。** 「真横なら 5/5、斜めなら 0/2」と言い切る方が、
> 「うまくいった例だけ見せている」への備えになる。

### ② 判定（M7 第1層）— **学習せずに落とせる**

```
B1（短く描いた）  水平到達 0.680 m  →  ❌「目標 0.8 m に届きません。1.30 倍に伸ばしてください」
A1 / A2 / B2      1.006 / 1.181 / 1.226 m  →  ✅
```

**幾何だけで約1秒。学習は一切回していない。**
→ **明らかに破綻した形は、4時間の学習を回す前に修正指針つきで返せる。**

### ③ 助言（M7）— **従わせると本当に良くなる。両方向で確かめた**

| 助言の向き | 内容 | 従わせた結果 |
|---|---|---|
| **増やす**（第1層） | 「腕を 1.99 倍に伸ばせ」 | **−396.92 → −0.33**（残り 397 mm → 0.33 mm） |
| **減らす**（第3層） | 「この関節は 7 % しか使っていない。固定してよい」 | **−6.30 → −5.32**（落ちるどころか良化） |

**減らす側の要点は「助言が出ていない方」**: 同じ関節を押しタスクで固定したら
**203.40 → 179.89 と悪化**した（押しでは使用率 41 % で助言は出ていない）。
→ **同じ関節が、到達では余り、押しでは必要。診断はタスクごとに要否を判断している。**

> 話し方: ここが一番強い。**「助言が正しいことだけでなく、黙っていた判断も正しかった」**まで言う。

### ④ ⚠️ 言えないこと（自分から言う）

- **形態どうしの順位は主張しない。** 縦型 3 形態でシードを 2 本にしたら**順位が入れ替わった**。
  増やしても解決しない（1 条件 718 シード必要）ので、**順位に依存しない主張だけを残す**方針にした
- **シード数が少ない**ので「頑健」とは言わない

> 話し方: **時間が無ければ ④ は口頭だけ。** ただし**聞かれる前に自分から言う**方が強い。

## スライド10: ゴール（1:10）

### 修論の結論として書くこと

1. **手描きスケッチから、タスク適性を試作前に判定できるシステムを構築した**
   （前段の頑健性・判定の妥当性・助言の有効性を、それぞれ実験で確かめた）
2. **判定は「学習せずに落とす」層と「学習して比べる」層に分かれる**
   幾何で決まる部分は約1秒、そうでない部分は学習が要る、という**費用の二極化**
3. **助言は増やす方向・減らす方向の両方で閉ループが成立する**

### 残り5か月でやること

| | やること | なぜ |
|---|---|---|
| **1** | **手描きの例数を増やす** | いまは 5 例。前段の頑健性を**成功率として**報告するには足りない |
| **2** | **前段のばらつきを詰める** | 同じ意図で描いた 2 枚で総リーチが 18 % ずれる。**原因は画像整形側**と特定できた（三次元化は ±0.7 %）ので、**プロンプトを詰める余地がある** |
| **3** | **タスクを増やす** | いまは 到達・押し・目標位置への押し の 3 つ。**パックの位置が毎回変わる**課題を追加中 |

> 話し方: **2 が一番説明しやすい。** 「犯人が分かったので次は直せる」という筋になる。

### ⚠️ やらないと決めたこと（聞かれたら）

- **形態どうしの順位を主張するためにシードを増やすこと** — 1 条件 718 シード必要で、
  修論まで 150 日では届かない。**順位に依存しない主張だけを残す**方が安い
- **把持** — 指の長さや接触形状の話になり、リンク長と関節位置を抽出する本手法の枠組みで扱えない
