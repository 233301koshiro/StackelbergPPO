> **対象の略号**: 予＝予備審査論文、正＝修論の正式版（[修論ドラフト/](../../修論ドラフト/)）、口＝修論の口語版（[修論_口語版/](../修論_口語版/)）、デ＝デッキ「予備審査_秋田」、図＝図の台本と画像、木＝drawio（主張の木・M6の仕組み・システム図 3 種・実験基盤説明。`md_の木` は論文の中身ではないので除く）、他＝想定問答・知見総括表・主張の木など。

## 1. 機械で確かめる（PDF の本文に対して）

md には本文から外す執筆メモがあり、md を grep すると誤検出が出る。ビルドした PDF の文字を見る。

```bash
python3 scripts/build_yobi_paper_pdf.py && python3 scripts/build_thesis_pdf.py && python3 scripts/build_kougo_pdf.py
d=$(date +%Y%m%d); for f in 予備審査論文 修論ドラフト 修論_口語版; do pdftotext docs/pdf/${f}_$d.pdf /tmp/$f.txt; done
for pat in 助言 順序づけ 順序付け 順位づけ 中間（スケール） 中間スケール 文章のみ ゼロから生成 短腕（総リーチ 謝辞 執筆メモ; do
  echo "$pat: $(grep -c "$pat" /tmp/予備審査論文.txt) / $(grep -c "$pat" /tmp/修論ドラフト.txt) / $(grep -c "$pat" /tmp/修論_口語版.txt)"; done   # すべて 0
grep -c "⌈" /tmp/予備審査論文.txt /tmp/修論ドラフト.txt /tmp/修論_口語版.txt   # 各 1（式の行だけ。本文中の記号は 0）
pdfinfo docs/pdf/予備審査論文_$d.pdf | grep Pages                          # 15（2026-11-19 時点）
for pat in 助言 順序づけ 順位づけ 中間 手書き 中くらいの長さ 粘性 検証項目; do echo "$pat: $(python3 scripts/drawio_text.py | grep -c "$pat")"; done   # drawio。すべて 0（11-19 から）
python3 scripts/check_colloquial.py && python3 scripts/check_docs_consistency.py && python3 scripts/check_section_refs.py && python3 scripts/check_claim_tree.py
```

「順位づけ」は 11-19 の通しの確認で予の概要・口 1 章・2 章に残っていた（「順序づけ」しか見ていなかった）。「執筆メモ」は口語版のビルドが本文中の 📝 執筆メモを落としておらず、口 4 章の 2 つが PDF に出ていた（`build_kougo_pdf.py` を直した。「（口語版の注）」は読者向けなので 1 のまま残る）。

drawio は PDF にも md の検査にも入らないので、`drawio_text.py` で文字を出して同じ語を grep する（11-19、ユーザー「よく考えたら drawio もするべき」。M6の仕組み に「中間」が 2 つ、修論 図 3.1 の元のシステム図に「手書きスケッチ」が残っていた）。「手書き」は予と正の参考文献（学部研究の題名）に 1 つずつあり、題名なので直さない。

⚠️ 修論の「壊れる」は付録A のプロンプトの全文（2 か所）、口語版の 1 か所は第3章の別の話で、この一覧の対象ではない。
