## 2. グループ別の要約

### 2.1 形態と制御の共同設計（co-design）

**[1] Stackelberg PPO** — Dai, Wang, Ashley, Schmidhuber, ICLR 2026（✅ 原文確認 10-19）

| 項目 | 内容 |
|---|---|
| 問題 | 従来の手法は、形態を更新するとき制御を固定とみなす。そのため形態の更新が制御の適応とかみ合わず、学習が不安定になる |
| 方法 | 形態を Leader、制御を Follower とする Stackelberg ゲームとして扱う |
| Leader の勾配 | 直接の項と、Follower の最適応答を通る間接の項の和 |
| 間接の項の求め方 | 陰関数微分で求める（交差微分 × Follower のヘッセ行列の逆） |
| 微分できない境目への対処 | 形態と制御の境目は微分できないので、尤度比で期待値として書く（定理 1） |
| ヘッセ行列の扱い | Fisher 情報行列＋λI で近似し、共役勾配法とヘッセ行列・ベクトル積で解く |
| 実験 | MuJoCo のタスク（Crawler・Stepper・Pusher など）、seed 7 つ、比較相手は BodyGen・ESS・NGE・Transform2Act |
| 結果 | 最も強い比較手法より平均 +20.66 %、3D の難しい 4 タスクでは +32.02 % |
| 輪講で突っ込める点 | λ と Fisher のアブレーションは 1 タスクだけ。図 3 の網掛けは標準誤差か標準偏差かで、キャプションと本文が食い違う |
| 本研究での使い方 | 良い形を作る道具ではなく、形の良し悪しを判定する道具として転用する（2.3） |

**[2] BodyGen** — Lu et al., ICLR 2025（✅ 原文確認 10-19）

| 項目 | 内容 |
|---|---|
| 問題 | Transform2Act には 3 つの弱点がある。GNN では遠い関節に情報が届きにくい。関節ごとの MLP でパラメータ数が膨らむ（19.64M）。設計段階に報酬の信号が届きにくい |
| MoSAT | 全リムの間で自己注意を取る |
| TopoPE | 根からの経路で位置を符号化する。形態が変わっても、同じ部分構造には似た埋め込みが付く |
| Enhanced-TCA | 設計段階と制御段階で価値ネットワークを分ける |
| 流れ | トポロジー設計 → 属性設計 → 制御を PPO で学習する |
| 実験 | MuJoCo の 10 環境 |
| 結果 | Crawler で 10,382（Transform2Act は 4,186） |
| アブレーション（Crawler） | MoSAT を外すと 819、TCA を外すと 4,994、TopoPE を外すと 7,491 |
| 規模 | 1.43M パラメータ |
| 輪講で突っ込める点 | 「最も強い比較手法より平均 +60.03 %」の出し方が本文だけでは追えない（最も強い相手は環境ごとに違う） |
| 本研究での使い方 | このリポジトリはトポロジーを固定している（`fix_skeleton=true`）ので、使っているのは属性設計と制御の 2 段だけ |

**[3] Transform2Act** — Yuan et al., ICLR 2022（Oral）
- 形態を作り変える行動と、制御の行動を 1 つの条件付き方策にまとめた。形態の探索そのものを強化学習の枠組みに載せた。

**[4] Neural Graph Evolution（NGE）** — Wang et al., ICLR 2019
- GNN で形態どうしの重みを共有し、進化戦略で形態を探す。

**[5] Evolving Virtual Creatures** — Sims, SIGGRAPH 1994
- 仮想生物の体と制御を同時に進化させた。co-design の原点。

**[6] Reinforcement Learning for Improving Agent Design** — Ha, Artificial Life 2019
- Gym の環境で、脚の各部の長さや太さを方策と同時に最適化した。タスクに合った体を自動で得られることと、学習が楽になることを示した。

**[7] Jointly Learning to Construct and Control Agents** — Schaff et al., ICRA 2019
- 形態パラメータの分布を持ち、方策と同時に学習する。分布はスコア関数推定（方策勾配）で更新する。

**[8] Proximal Policy Optimization（PPO）** — Schulman et al., 2017
- クリップした代理目的で方策を安定して更新する、強化学習の標準アルゴリズム。

### 2.2 スケッチ入力・三次元形状からの構造推定

**[9] RobotSketch** — Lee et al., SIGGRAPH 2024 Emerging Technologies
- VR 空間で脚ロボットを 3D スケッチし、強化学習で歩行を獲得させる対話的なシステム。
- 修論では次の 2 点を差分としている。
  - 関節の配置など物理的な整合性はユーザーの判断に委ねられている。
  - 評価は歩行という 1 タスクだけ。

**[10] Teddy** — Igarashi et al., SIGGRAPH 1999
- 2D の輪郭線を膨らませて 3D 形状を作る。専門知識の無い人でも形を作れることを示した、先駆的なシステム。

**[11] Free2CAD** — Li et al., ACM TOG 2022
- 手描きの線を CAD の操作列に変換する。

**[12] Sketch-based modeling: A survey** — Olsen et al., Computers & Graphics 2009
- スケッチベースモデリングの古典的なサーベイ。

**[13] Deep Sketch-Based 3D Modeling: A Survey** — Tono et al., 2026
- 深層学習以降のスケッチベースモデリングのサーベイ。

**[14] URDF-Anything** — Li et al., NeurIPS 2025
- 点群に 3D マルチモーダル LLM を使い、部品の分割と関節パラメータの推定をまとめて行い、URDF を作る。
- 修論では次の点を差分としている。
  - 学習による推定の誤りは、正常な出力と見分けがつかない。
  - 本研究は色マーカーと決定的な抽出で、構造の抽出を失敗が検出できる処理に置き換えた。

### 2.3 作業空間解析・タスク駆動設計

**[15] Capturing robot workspace structure** — Zacharias et al., IROS 2007
- ロボットが到達できる範囲を capability map として表す。
- 本研究の第1層（到達できるかの幾何判定）はこの系統の最小形であり、新規性は主張していない。

**[16] Manipulability of Robotic Mechanisms** — Yoshikawa, IJRR 1985
- 可操作性の指標。
- 修論ではこれと対比して述べている。可操作性が測るのは形態が原理的に何をできるかであり、制御がその能力を引き出せるかは測らない。

**[17] Task-based limb optimization for legged robots** — Ha et al., IROS 2016
- タスクの要求から脚の形を最適化する。

**[18] Task-Aware Morphology Optimization of Planar Manipulators via RL** — Mishra & Chakrabarty, arXiv 2025
- 平面アームの形態を強化学習で最適化し、3 種類の軌道追従タスクごとに形態を求める。
- 修論では次の 2 点を差分としている。
  - タスク間で順位が入れ替わることを検証していない。
  - 最適化がうまくいかないとき、その原因を返す仕組みを持っていない。

### 2.4 説明可能性・反実仮想説明

**[19] Counterfactual Explanations Without Opening the Black Box** — Wachter et al., Harvard JOLT 2018
- 「入力がどう違っていれば結果が変わったか」を示せば説明として機能すると論じた。判定を覆す最小の変更が最も役に立つ、とする。

**[20] Actionable Recourse in Linear Classification** — Ustun et al., FAT* 2019
- 判定を覆す変更は、受け手が実際に操作できる変数で表すべきだとして、actionable recourse を定式化した。

**[21] Explainable generative design in manufacturing** — Klar et al., JMS 2024
- 強化学習で工場のレイアウトを設計し、その説明可能性を扱う。分析者向けの可視化が中心。

### 2.5 物理の値の根拠

**[22] Electro-mechanical modeling and identification of the UR5 e-series robot** — Clochiatti et al., Robotica 2024
- UR5e の関節のモーターと減速機の慣性、および減速比を同定した。
- 修論 表 4.2 の回転子の慣性（armature）の根拠（系譜 9-246）。
