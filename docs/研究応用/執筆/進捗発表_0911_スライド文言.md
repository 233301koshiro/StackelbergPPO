## 下段: **各段階でどこが壊れたか**（実測つき）

```
① 立体にする
　　★ 絵の中の「比」だけが効く。画素サイズや紙の実寸は効かない
　　　 （出力は必ず最長辺が 1.0 に正規化される。GLB 4件で実測）

　　★ 指定した純マゼンタは、そのままの色では出てこない（最大 86／チャネルずれる）
　　　 公称色に固定しきい値 → 2メッシュとも検出失敗
　　　 しきい値を手で広げる → 必要な値がメッシュごとに違い、関節位置が最大 12.8 mm ずれる
　　　 → 基準色をメッシュごとに推定して、初めて誤差 1 mm 以内

③ リンクに切り分ける
　　★ 腕が寝ると、関節がほぼ同じ高さに並んで原理的に切れない
　　　 → 検知して止まる。誤った形のまま先へ進まない

④ 寸法を測る
　　★ 関節の球がリンクの長さに混入し、総リーチが 14 % 過大になっていた
　　　 → 測った値が本当にその形で実現するかを、別経路で毎回検算している
```


## E. 実験の作法

### E1 ★★★ 順位を取り下げた経緯

```
縦型に立てた3つの形の順位を、一度は主張しかけて取り下げました。

　1つ目の乱数では「到達は単調に悪化」「押しは A1v が突出」と読めた
　2つ目の乱数で、どちらも崩れた
```

### I5 ★☆☆ 自己チェックが検出器として成立していなかった（9-69）

