# 結合テスト — 「てんで見込み違いのロボット」を直せるか

> ⭐ **ユーザーの提案（2026-09-26）**。M1〜M7 の**単体テストではなく結合テスト**。
> 既存の E2E（[E2E実走_手描き入力.md](E2E実走_手描き入力.md)）は
> **「通るか」**を測るものであり、本テストは**「通らないものを直せるか」**を測る。

## なぜ単体テストでは見えないか

各工程は個別に検証されている。⛔ **だが「棄却 → 助言 → 修正 → 再入力 → 達成」を
1 本の通しで回した記録が無い。**関連する材料は 2 つあるが、**別々の実験**である。

| 既にあるもの | 何が欠けているか |
|---|---|
| **9-19**: B1（腕÷絵 0.705）が第1層で棄却され「1.02 倍に伸ばせ」が出た | ⛔ **その助言に従った先が無い**（B1 は意図的に学習させていない） |
| **9-11**: 不適合形態（−396.92）に 1.99 倍を適用して −0.33 / −0.27 | ⛔ **形態は手書きの XML**。パイプラインの出力ではない |

⭐⭐ **つまり「パイプラインが出した不適合形態を、パイプラインの助言で直して、達成まで持っていった」例が 1 つも無い。**

## 測ること（結合でしか出ない 4 つ）

| # | 問い | 単体では見えない理由 |
|---|---|---|
| **1** | **M1 の整形が判定を変えていないか** | 人が描くと手先が垂れるが、M1 は Z 分割の都合で**立ち上げる**（助教の指摘16c）。⛔ **立ち上げが総リーチを変えれば、判定は「人が描いた形」ではなく「M1 が直した形」を見ている** |
| **2** | **助言が生成物に対しても有効か** | 9-11 の 1.99 倍は**手書き XML** に適用した。⛔ **生成物はリンク比が揺れる**（9-22: 同趣旨の 2 枚で総リーチが 18 % 違う） |
| **3** | **修正形態が再入力を生き延びるか** | ⛔ **再生成するとまた揺れる**。⭐ **だから再生成せず XML をスケールする経路が要る**（指摘12） |
| **4** | ⭐⭐ **助言が人間に実行可能か** | 「1.99 倍に伸ばせ」と言われた利用者は**描き直すのか**。⛔ **描き直せば揺れが入る。**⭐ **自動スケールが無いと閉ループは人手で切れる** |

⭐⭐ **4 が本テストの核心であり、助教の指摘12（自動スケール）に研究上の意味を与える。**
⚠️ **指摘12 は当初「研究の主張は増えない。価値はデモの側」と評価した**（対応方針）。
⭐ **本テストの連結子として見ると評価が変わる** — 無いと結合テストが人手で分断される。

## 手順

| 段 | やること | 合格条件 |
|---|---|---|
| **0** | ⭐ **わざと不適合な絵を 1 枚描く**（既存 B1 より更に短い／関節が足りない／手先が垂れた） | — |
| **1** | M1 → M2 → M3 → M4〜M6 で XML まで生成 | ⭐ **通過する**（前段は壊れない） |
| **2** | **M7 の第1層が棄却し、必要倍率 N を返す** | ⭐ **棄却される。**⛔ 通過したら不適合の作り方が甘い |
| **3** | ⭐ **N 倍にスケールした XML を自動生成**（指摘12 の連結子） | ⭐ **描き直さずに済む** |
| **4** | 再入力して M7 にかける | ⭐ **通過する** |
| **5** | 学習（2 seed） | ⭐ **目標に到達する** |

⚠️ **各段で「前段の出力」をそのまま使う。**途中で人が数値を作り直したら結合テストではない。

## 記録すること

- 段 1 で**手描きの比と生成物の比がどれだけずれたか**（問い 1 の答え）
- 段 2 の**必要倍率 N**、段 4 の**判定の変化**
- 段 5 の**到達距離**、対照（修正前の形態）との比較
- ⛔ **どこかで落ちたらそこが結合の穴**。⭐ **落ちたこと自体が結果である**

## やらないこと

- ⛔ **成功するまで絵を描き直さない。**落ちたら落ちた理由を書く
- ⛔ **助言の値を手で調整しない**（余裕の上乗せは 9-30 で撤去済み）
- ⛔ **M1 のプロンプトをこのテストのために変えない**（変えたら別の実験）
