# タスク間形態差の定量比較 — 「そんな変わった？ハイパラの範疇では？」への回答資料

> **このファイルの役割**: 先生の指摘（2026-07-17）「タスクが似ているから動画では形態最適化の違いが分かりにくい。同じタスクでもパラメータ次第で形態に多少差は出るのだから、その範疇を出ていないのでは？」に対して、
> 具体的に**どこがどれだけ変わったか**と、**それがシード揺らぎ（同条件の再現誤差）の範疇でない**ことを一次データで示す。

## 1. 前提: この比較は「ハイパラの範疇」を測れる設計になっている

6 run はすべて:

- **同一の初期形態**: リンク長 L1=0.30 / L11=0.25（最大リーチ 0.55m）、gear=(150, 100)
- **同一のハイパーパラメータ**: PPO 設定・学習率・エポック数（1000）・ネットワーク構造・探索範囲（gear [20,400]）まで全部同じ
- 変えたのは **報酬の定義（= タスク）と乱数シードの2つだけ**

つまり「同じタスクでシードだけ変えた対（L1 vs L1_s2 など）」が、先生の言う**「同条件でも出る形態差」の実測値そのもの**になっている。タスク間の差がこのシード内揺らぎを超えているか、が検証すべきことのすべて。

## 3. シード揺らぎの範疇でない3つの論拠

### 論拠①: 「シードで動く軸」と「タスクでしか動かない軸」が分離している

これが核心。各タスクには**シードを変えても 1mm も動かない軸**があり、その軸の値がタスク間では正反対の端に飛ぶ。

| 軸 | Reach（2 seed） | Pusher（2 seed） | TP（2 seed） |
|---|---|---|---|
| 肩 gear | **20, 20**（揺らぎ幅 0） | 400, 98 | 400, 181 |
| 肘 gear | 207, 20 | **400, 400**（揺らぎ幅 0） | 244, 400 |
| max(gear) | 207, 20 — **400 に一度も触れない** | 400, 400 | 400, 400 |

- Reach の肩 gear はシード内揺らぎ **0**（両方とも下限 20 ぴったり）。タスクを Pusher に変えると 98〜400 に飛ぶ。**差 78〜380 vs 揺らぎ 0**
- Pusher の肘 gear も揺らぎ 0（両方 400）。Reach に変えると 20〜207。
- 一方、シードで大きく動く軸もある（Pusher の肩 gear は 98↔400、Reach の肘 gear は 20↔207）— これらは**タスクが決めない自由パラメータ**で、先生の言う「同タスク内の形態差」はここに現れている。**タスクの署名（signature）となる軸とは別の軸**である

連続的な揺らぎは「張り付く境界の向き」を反転させない。下限張り付き（20）と上限張り付き（400）は量的な差ではなく**質的な差**で、これが 2/2 シードで再現している。

### 論拠②: その形態差は成績に因果的に効く（飾りではない）

「パラメータが違っても性能が同じなら、違いに意味はない」への反論:

- **Reach の低 gear は頑健性を買っている**: n=10 の確率的評価で、gear(20,20) の L1_s2 は **10/10** で目標 12mm 以内に着地、肘 gear 207 の L1 は **5/10**（mean dist 3.6 倍悪化）。gear の違いは行動の質を実測で変える（形態比較.md「L1/L1_s2 完走解析」）
- **M 系 ablation**: Pusher の性能向上のうちリンク長の寄与 46%・gear の寄与 19%・相互作用 35%（凍結 C=16.75 → L2=102.16 の分解）。形態パラメータは成績の主要因

### 論拠③: 変化の方向が力学的に説明できる（偶然の散らばりではない）

- Reach の肩 gear 下限: 方策ノイズ × gear = 保持中のジッタ。到達精度タスクではトルクが強いこと自体が害
- Pusher の肘 gear 上限・長リーチ: 先端速度 = 角速度 × 総リンク長。一撃の運動量に単調に効く
- Reach のリーチ 0.91〜1.10: 目標 0.8m に対する**必要十分で止まる内部解**（探索上限 1.44 まで伸ばせるのに伸ばさない）。Pusher は 1.23〜1.72 と cube（中心 1.0m）を大きく越えて伸ばす

「シードのせいでたまたま散らばった」なら、方向がタスクの力学要求と系統的に一致する理由がない。

## 4. 動画で分かりにくいのは事実 — 見せ方の提案

動画で見えるのはリンクの長さ比程度で、gear（トルク倍率）は静止画では**原理的に見えない**。提案:

1. **図を先に見せる**: [morphology_task_separation.png](../morphology_task_separation.png) — (a) gear 空間で Reach が左端・Pusher/TP が上端/右端に張り付く様子、(b) リーチ帯。「どの軸がどれだけ動いたか」は動画より図が強い
2. **動画は行動の違いを見せる材料に切り替える**。行動は数値が桁で違う:
   - Reach: 先端がサブミリ精度（hover 1.9〜2.8mm）で静止
   - Pusher: cube を 11〜23 m/s で吹き飛ばす（bat 打撃）
   - Target-Pusher: 2 m/s 弱で押し、目標の 0.4〜0.5cm 手前で止めて残り ~925 ステップ保持
3. 動画に cube 速度・静止位置の数値を字幕で載せると「同じに見える」問題が消える

## 5. 正直に認める限界（先に言う方が強い）

- **リーチ帯は Reach と TP が重なる**（1.10 vs 1.10）。リンク長だけではタスク3つは分離しない。分離するのは gear プロファイル + 行動クラスタ
- **TP は形態だけでは Pusher と区別できない**（高 gear・中リーチで同型）。第3タスクの識別は行動（押して止める vs 吹き飛ばす）で成立している。これは弱点ではなく「形態だけ見てもタスク適性は判定できない = 制御の習熟込みで評価する本研究の設計が必要」という主張の根拠（想定問答 Q1 の 4 と同じ構図）
- **n=2/タスクなので統計検定はしない**。主張は「境界張り付きの方向が seed を跨いで一致し、タスクを跨いで反転する」という質的パターン + 力学的説明 + n=10 の行動検証で支える
