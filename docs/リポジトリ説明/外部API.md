# 外部 API の使い方と費用（Tripo3D・Gemini）

> **役割**: キーの置き場・単価・残高・実際の回し方を 1 枚にまとめる。
> ⚠️ **キーそのものは書かない。**`.env`（gitignore 済み）に置く。

---

## Tripo3D（M2: 画像 → 三次元形状）

### 費用と残高

| | |
|---|---|
| 入金 | **10 ドル ＝ 1000 クレジット**（先払い。指導教員が 2026-09-18 に入金） |
| **1 生成** | ⭐ **30 クレジット ≒ 0.30 ドル** |
| 1000 クレジットで | **約 33 回** |
| 残高の確認 | `python3 scripts/tripo_api.py --balance` |

**⭐ 課金されるのは生成だけ。** 次は**すべて無料**である。

| 操作 | 課金 |
|---|---|
| 残高照会 | 無料 |
| パラメータ検証 | 無料 |
| **画像アップロード** | ⭐ **無料**（`image_token` の取得まで） |
| **生成（`image_to_model`）** | ⛔ **30 クレジット** |

⚠️ **アップロードまで無料なので、生成の直前まで課金なしで確認できる。**
**新しい画像を試すときは、まずアップロードだけ通すこと。**

### キーの置き場

```bash
# .env（gitignore 済み。⚠️ リポジトリには絶対に書かない）
TRIPO_API_KEY=tsk_...
```

⚠️ **`git check-ignore -v .env` で追跡されないことを確認済み。**
⚠️ **キーはチャットに貼られた時点で会話ログに残る。**気になるなら管理画面で再発行する。

### 使い方

```bash
python3 scripts/tripo_api.py --balance                       # 残高（無料）
python3 scripts/tripo_api.py --image <画像> --seed 42 --out <出力先>
python3 scripts/tripo_api.py --verify-seed --image <画像>     # 同 seed で 2 回（60 クレジット）
```

### ⭐ 再現性について — **実測した結果**（9-115）

⚠️ **公式は「同じ seed なら同一のモデル」と明記するが、厳密には偽である。**

| 比べる量 | 結果 |
|---|---|
| GLB の sha256 | ⛔ **異なる** |
| 頂点数 | ⛔ **104,959 / 104,963（4 個違う）** |
| 面数・体積 | ✅ 一致 |
| ⭐ **外接箱** | ⭐ **完全一致** |
| ⭐ **主軸・最遠点距離** | ⭐ **完全一致** |

```
Web UI の揺れ（9-39 実測）: ±0.7 %
⭐ API（同 seed）の揺れ    :  0.0000 %
```

**⭐ 後段（M3〜M4）が使う量は完全に一致するので、研究方針 段 2〜4 の
「M2 の揺れをゼロにして残る揺れを M1 に帰属する」は成立する。**
⚠️ **ただし「同一」とは書かない。「後段が使う量が一致する」と書く。**

### ⚠️ 注意

- ⚠️ **1 回の `--verify-seed` で 60 クレジット（2 生成）。** 残高を見てから回す
- `model_version` を指定すると版を固定できるが、**不正な値は `code 1004` で弾かれる**
- 生成は 3〜5 分かかる。`tripo_api.py` が完了まで待つ

## Gemini（M1: スケッチ → マーカー付き画像）

⭐⭐ **2026-09-30 に疎通・費用まで確認済み**（系譜 9-191）。

### ⭐⭐ モデルの選択 — **`gemini-3-pro-image` を使う**

⚠️ **ブラウザ時代の M1 は「3.1 Pro（拡張機能）」**である（E2E実走_手描き入力.md）。
⛔⛔ **既定を 2.5-flash にすると、それまで成立していたものが崩れる恐れがある。**

| | ⭐ 3-pro-image | ⚠️ 2.5-flash-image |
|---|---|---|
| マーカー数 | **3** ✅ | **3** ✅ |
| ⭐ **区間比**（ブラウザは 0.97） | ⭐ **1.00 / 1.00** | 1.00 / 0.99 |
| 目視 | ⭐ **球が分離。ブラウザに近い** | ⛔ **球がリンクに埋まる。先端カプセルが画面端で切れる** |
| ⛔ **提供** | ⭐ **継続** | ⛔⛔ **2026-10-02 に廃止** |

⛔⛔ **2.5-flash は 2026-10-02 で終わる。**⭐ **選択の余地は無い。**

### ⭐⭐ 費用 — **実測トークン × 公式単価**

⛔⛔ **画像生成モデルに無料枠は無い**（公式明記）。⭐ **呼んだ時点で課金される。**

⭐ 実測（B1 手描き 1 枚、`--check` ではなく実生成）:

```
[usage] prompt=1242  output=1392（うち画像 1120）  total=2915
```

| モデル | 入力 | 出力 | ⭐ **1 枚** |
|---|---|---|---|
| ⭐ **`gemini-3-pro-image`** | $2.00/1M → **$0.0025** | $120/1M → **$0.1344** | ⭐ **$0.137（約 21 円）** |
| `gemini-2.5-flash-image` | $0.30/1M → $0.0004 | **$0.039/枚** | **$0.039（約 6 円）** |

⭐ **実測 1120 トークン × $120/1M = $0.1344** は公式の **「$0.134 per 1K/2K image」と一致**する。
⭐ **したがってトークン数から費用を事前に見積もれる。**

⚠️ **10 枚の遵守率測定（9-84）は 3-pro で約 $1.37（約 210 円）。**

### キーの置き場

```bash
# .env（gitignore 済み。⚠️ リポジトリには絶対に書かない）
GEMINI_API_KEY=AIza...      # ⭐ 39 文字。38 文字なら 1 文字欠けている
```

⚠️ **キーはチャットに貼られた時点で会話ログに残る。**気になるなら管理画面で再発行する。

### 使い方

```bash
python3 scripts/gemini_api.py --check       # ⭐ 無料。models.list で実疎通
python3 scripts/gemini_api.py --sketch data/test/B1/sketch/B1_hand.jpeg --name B1 \
    --out data/api/B1.png                   # ⛔ 課金（約 21 円）
GEMINI_MODEL=gemini-2.5-flash-image python3 scripts/gemini_api.py ...   # 版を替える
```

⭐ `--name B1` は `data/test/B1/sketch/measured.json` から**実測比**を読む。

### ⛔⛔ 踏んだ罠（2026-09-30）

| # | 罠 | 是正 |
|---|---|---|
| ⛔⛔ **1** | **`--check` が API を叩かずキーの有無しか見ていなかった。**1 文字欠けた無効なキーに「✅ 準備完了」と答えた | ⭐ **`models.list`（無料）で実疎通する** |
| ⛔⛔ **2** | **`make_m1_prompt.py` に無い `--links` を渡し、引数エラーで stdout が空。`returncode` を見ていないので「プロンプト 0 文字」のまま 2 枚生成**（⛔ **約 26 円の無駄**） | ⭐ **失敗と空文字列を必ず例外にする** |
| ⚠️ **3** | `models.list()` は遅延評価。**クライアントを変数で保持しないと** `Cannot send a request, as the client has been closed` | ⭐ クライアントを保持する |

### ⚠️ 残る確認事項

⭐ **「同じキーで画像生成モデルを呼べるか」は解決**（✅ 呼べる。画像系 6 モデル）。
⚠️ **残るのは予算の承認**: ⛔ **無料枠が無く 1 枚 21 円**なので、**何枚回してよいかは指導教員の判断**である。

### ⚠️ M1 が要るのは「画像生成」であって「検出」ではない

ユーザー提供のサンプルは `gemini-robotics-er-1.5-preview` で**点を検出して JSON を返す**ものだった。
**M1 は手描きスケッチから整形画像を生成する工程**なので、モデルが違う。
⭐ **入力の渡し方（`types.Part.from_bytes`）だけ流用した。**

⚠️ **Tripo と性質が違う。**公式が **seed の決定性を保証していない**（研究方針 段 2〜4）。
⭐ **したがって M1 の揺れは原理的に残る。**それを n 回の試行で測るのが 9-84 の設計である。
