## 2. 能動的に見つける 7 つの方法

### 方法 1. ⭐⭐ 差分テスト — 同じ XML を MuJoCo と Choreonoid で動かして比べる

この研究の物理の穴の大半は「**MuJoCo（原論文）が暗黙にやっていることを、Choreonoid への移植が落とす**」型だった。
同じ XML・同じ台本の行動（範囲外の制御入力・深い接触・壁への衝突・減衰だけの惰行を含む）で両方を動かし、関節の動き・物体の位置を比べる。差が出た量が「移植で落ちた物理」の候補になる。

- 見つけられた過去のもの: Bug 1・2（減衰）、Bug 42（慣性の向き）、Bug 44（円柱が空）、9-98（壁が無い）、9-173/9-198（反発係数）、Bug 57（深い接触を捨てる）、**Bug 60（制御入力を切らない）**＝**8 件**
- 道具: MuJoCo 3.9 は入っている（`audit_implicit_physics.py` が使用）。Choreonoid 側は `record_arm_trace.py` と同じ入口
- ⚠️ 差＝バグではない（接触モデルは違って当然）。**台本の 1 項目ごとに「差が出るはずか」を先に書いてから比べる**

### 方法 2. ⭐⭐ 不変条件の見張り — 「物理的にありえない値」を機械で拾う

結果がどうであれ必ず成り立つはずの量を、学習ログと再生の軌跡で毎回確かめる。

| 不変条件 | 破ったときの例 |
|---|---|
| 1 step の報酬は理論上の床と天井の間（到達なら −(届く距離＋制御コスト)〜0） | **Bug 60**（−1,900 万） |
| |制御入力| ≤ ctrlrange、トルク ≤ ギア比 | **Bug 60** |
| 物体・腕は壁と可動域の内側、リンクは床より上 | Bug 39、9-93、9-154 |
| 対象は腕に触れるまで動かない | Bug 55、Bug 6 |
| 台座など固定したものは動かない | Bug 58 |
| 離れたリンクどうしのめり込みは小さい | Bug 57 |

⭐ **試しに全 run の学習ログを「1 step の平均報酬がその run の中央値の 20 倍を超えるか」で走査した（10-12）。旗が立ったのは 4 本で、Bug 60 の 1 本（−366.6）と、ep0 の門の罰が乗った 3 本だけ。**誤報が少なく、ep0 で Bug 60 を拾えた。

### 方法 3. ⭐ 反実仮想の再生 — 物理のつまみを 1 つ変えて、結果がどれだけ動くか

学習済みの方策を、物理の設定を 1 つだけ変えて再生する（制御入力を切る・閾値・自己干渉・反射・減衰を 2 倍）。**「効かないはず」のつまみで結果が大きく動いたら、方策がその穴に頼っている。**
- 実例: 9-241（切って再生したら密度の押しの箱が 19.6 → 14.9 m）、9-227（閾値 1.0 で再生したら long の箱が 4.4 → 2.6 m）、9-235（台座を立てて再生したら 0 m）
- 費用: 1 本 10 秒程度（再生は速い）。⭐ **今回 3 回とも、これで「頼っている」が確定した**

### 方法 4. ⭐ 由来の監査 — 数値ごとに「どこから来たか」を言えるか

XML・cfg の値ごとに、由来を「スケッチから測った／物理から導いた／文献／**既定値（誰も選んでいない）**」に分ける。既定値は、条件が変わったとき（自己干渉を入れた、密度を変えた）に突然効き始める。
- 見つけられた過去のもの: 台座の球（9-241、既定値）、`armature=1`（9-47）、密度 5.0（9-126）、ギア上限 400（9-129）、`solref`（9-86）、制御コストの既定 1e-4（Bug 59 の正体）
- `audit_implicit_physics.py` は「XML に書かれていない MuJoCo の値」だけを見ている。**生成スクリプトの既定値（`topology_to_xml.py` の `DEFAULT_ROOT` など）とコードの既定値（`reward_specs.get(..., 既定)`）は見ていない**

### 方法 5. 測り方を 2 つ持つ

同じ量を独立な 2 つの道具で出し、食い違ったら止まる（例: 図の題と `check_self_penetration.py`、学習ログと再生）。過去の能動的な発見の多くはこれだった（Bug 10・18・47、9-239）。

### 方法 6. 仲間うちの外れ値

比べる組（`check_before_conclusion.py` の `COMPARISONS`）と seed の対の中で、1 本だけ桁が違う run を拾い、**先に再生する**。
- 実例: 9-240 の dist・実在（prox の 0〜1 mm に対し 57〜131 mm）→ 台座の球、9-105（版の混入）

### 方法 7. 起動行の差分

`check_before_conclusion.py` の「比べる相手」（9-238 で実装済み）。
