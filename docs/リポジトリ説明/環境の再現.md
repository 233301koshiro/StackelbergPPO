## 4. 追加でツールが要るときの入れ方

⚠️ **`pip install` はそのままでは通らない。** PEP 668 により Debian 系は
**システム Python への pip を機械的に禁止**している。

```
error: externally-managed-environment
```

**`--break-system-packages` は使わないこと。** torch 2.7.0+cu128 と Choreonoid バインディングが
同居しており、壊れると学習が止まる。**venv を分ける。**

```bash
python3 -m venv --system-site-packages /tmp/tools-venv
/tmp/tools-venv/bin/pip install <パッケージ>
/tmp/tools-venv/bin/python your_script.py
```

`--system-site-packages` を付けると venv からも torch・numpy が見える。
**2026-09-08 に python-pptx（pptx の読み書き）をこの方法で入れた。**

## 5. イメージのビルド（2026-09-08 に入手）

`docker/Dockerfile.add_akita_sp` と `docker/build_akita_sp.sh` をリポジトリへ取り込んだ。
**コンテナの一つ上の階層（ホスト側）にあったもの**で、それまでリポジトリに無かった。

```
ベース  repo.irsl.eiiris.tut.ac.jp/irsl_system:24.04_one
        Ubuntu 24.04 / Python 3.12 / Choreonoid 2.3（Python バインディング込み）
追加    OSMesa・GL・GLFW・GLEW・patchelf・xvfb
        MuJoCo 2.1.0 バイナリ（/ros_home/.mujoco。フォールバック用で通常は使わない）
        torch 2.7.0+cu128（sm_120 対応）・torch-geometric
        gym 0.26.2 ほか
```

### ⚠️ ビルドしても**いまの環境にはならない**。差分が3つある

**① `build_akita_sp.sh` が pull するタグが Dockerfile と違う**

```bash
docker pull ... irsl_system:noetic        # ← スクリプト
FROM        ... irsl_system:24.04_one     # ← Dockerfile
```

**pull は無意味で、`docker build` が `24.04_one` を自分で取りに行っている。**
`noetic`（Ubuntu 20.04 系）を取っても使われない。**紛らわしいので直すか消す。**
⚠️ README の「動作環境」も `irsl_system:noetic` と書いており、**同じ誤りが伝播している。**

**② Dockerfile に無いのに入っているものがある（後付け）**

| | 版 | 何に使うか |
|---|---|---|
| **trimesh** | 4.12.2 | **M3 のメッシュ分割。無いとパイプラインが動かない** |
| **imageio / imageio-ffmpeg** | 2.37.3 / 0.6.0 | **デモ動画の書き出し** |
| networkx | 3.6.1 | グラフ |
| pandas / psutil | 3.0.3 / 7.2.2 | 集計・プロセス確認 |

**ビルドし直すとパイプラインが動かない。** 復旧するには:

```bash
pip install --break-system-packages trimesh imageio imageio-ffmpeg networkx pandas psutil
```

⚠️ ここは Dockerfile が既に `--break-system-packages` を使っているので同じ流儀でよい。
**venv を分ける必要があるのは、コンテナ作成後に足す一時的な道具**（python-pptx 等）である。

**③ 版が上がっているもの**

| | Dockerfile | 実際 |
|---|---|---|
| hydra-core | 1.2.0 | **1.3.2** |
| numpy | 1.26.4（ベースイメージ） | **2.4.6** |

いつ・なぜ上がったかの記録が無い。**動いているので触らないが、再現時は実際の版に合わせる**
（[環境_pip_freeze_20260908.txt](環境_pip_freeze_20260908.txt) が正）。

## 6. まだ足りないもの（正直に）

- ✅ **Dockerfile は 2026-09-08 に取り込んだ**（`docker/`）。ただし上記のとおり
  **ビルドしただけではいまの環境にならない**
- ❌ **コンテナの起動コマンドが無い。** `docker run` / `compose` の記録が無いため、
  **マウント（`/userdir`）・GPU（`--gpus`）・X11（`DISPLAY=:1`）の指定が復元できない**。
  Remote Control も Choreonoid の GUI もここに依存する。**最優先で入手したい**
- ❌ **`devcontainer.json` が無い。** README は「VS Code Dev Container 推奨」と書いているが
  実物がリポジトリに無い
- `requirements.txt` を直していない。**直すと過去の run の再現条件が変わる**ので、
  「当時の記載」として残し、**この文書と `pip freeze` を正とする**方針にした
