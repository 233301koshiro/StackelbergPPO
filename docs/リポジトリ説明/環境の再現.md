## 4. 追加でツールが要るときの入れ方

⚠️ **`pip install` はそのままでは通らない。** PEP 668 により Debian 系は
**システム Python への pip を機械的に禁止**している。

```
error: externally-managed-environment
```

**`--break-system-packages` は使わないこと。** torch 2.7.0+cu128 と Choreonoid バインディングが
同居しており、壊れると学習が止まる。**venv を分ける。**

```bash
python3 -m venv --system-site-packages /tmp/tools-venv
/tmp/tools-venv/bin/pip install <パッケージ>
/tmp/tools-venv/bin/python your_script.py
```

`--system-site-packages` を付けると venv からも torch・numpy が見える。
**2026-09-08 に python-pptx（pptx の読み書き）をこの方法で入れた。**
