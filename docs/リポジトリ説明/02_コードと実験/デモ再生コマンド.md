# デモ再生コマンド

Choreonoid の画面で、完走済み run の best checkpoint を再生するコマンドをまとめる。
これは学習を開始するコマンドではない。

## 共通の準備

画面デモを起動する前に、コンテナ内で一度だけ実行する。

```bash
su ubuntu -s /bin/bash -c "DISPLAY=:1 xhost +SI:localuser:root"
```

学習中にデモを動かすと重いため、発表・録画時は学習を止めておく。

既定では 1 話を再生する。複数話を流す場合は第2引数に話数を指定できる。

```bash
bash scripts/demo_cnoid.sh <run> [episodes]
```

## 通常版

通常版は `/userdir/StackelbergPPO` の `scripts/demo_cnoid.sh` を使う。
引数と復元される run は次のとおり。

| 第1引数（run） | タスク | 画面上の扱い |
|---|---|---|---|
| `e2e_a1v_reach_phys_s2_ws` | Reach | 箱を隠し、目標を表示 |
| `e2e_a1v_pusher_phys_s2` | Pusher | 箱を表示 |
| `e2e_a1v_actuator_tp` | Target-Pusher | 箱と目標を表示 |
| `e2e_a1v_obspen_reach_phys` | 障害物 Reach（回避側） | 箱を隠し、目標を表示 |
| `e2e_a1v_obspen_reach_phys_sub5_s2` | 障害物 Reach（到達側） | 箱を隠し、目標を表示 |
| `hockey_bank9_phys_g10_blk3d_fs_ax` | Hockey | 既定で 3 話、ゴール位置を表示 |

例:

```bash
su ubuntu -s /bin/bash -c "DISPLAY=:1 xhost +SI:localuser:root"
bash scripts/demo_cnoid.sh e2e_a1v_reach_phys_s2_ws
bash scripts/demo_cnoid.sh e2e_a1v_pusher_phys_s2
bash scripts/demo_cnoid.sh e2e_a1v_actuator_tp
bash scripts/demo_cnoid.sh e2e_a1v_obspen_reach_phys
bash scripts/demo_cnoid.sh e2e_a1v_obspen_reach_phys_sub5_s2
bash scripts/demo_cnoid.sh hockey_bank9_phys_g10_blk3d_fs_ax
```

話数を指定する例:

```bash
bash scripts/demo_cnoid.sh e2e_a1v_reach_phys_s2_ws 5
```

### 発表用に使った結果の良い run

上の通常コマンドは、スクリプト内で固定された run を復元する。発表用動画で実際に使った主な run は次のとおりで、引数との対応が異なるものがある。

| タスク | 発表用動画・推奨 run | 備考 |
|---|---|---|
| Reach | `e2e_a1v_reach_phys_s2_ws` | `demo/phys_reach.mp4` の元 run |
| Pusher | `e2e_a1v_pusher_phys_s2` | `demo/phys_pusher.mp4` の元 run |
| 障害物 Reach | `e2e_a1v_obspen_reach_phys_sub5_s2` | `demo/phys_obstacle_reach.mp4` の元 run |
| Hockey | `hockey_bank9_phys_g10_blk3d_fs_ax` | `demo/phys_hockey.mp4` の元 run |

これらの run はスクリプトのタスク分岐に既定値として設定されている。

## RobotAssembler 版

RobotAssembler 版は `/userdir/StackelbergPPO_ra` worktree のスクリプトを使う。main 側の `scripts/demo_cnoid.sh` にはこの分岐がない。

```bash
su ubuntu -s /bin/bash -c "DISPLAY=:1 xhost +SI:localuser:root"
bash /userdir/StackelbergPPO_ra/scripts/demo_cnoid.sh <run> [episodes]
```

### 実装済みの引数

| 第1引数（run） | タスク |
|---|---|---|
| `ra15_pusher_beta_s2` | RobotAssembler Pusher、形態を学習 |
| `ra15_pusher_beta` | RobotAssembler Pusher、形態を学習 |
| `ra15_pusher_alpha` | RobotAssembler Pusher、形態を固定 |
| `ra15_pusher_alpha_s2` | RobotAssembler Pusher、形態を固定 |
| `ra15_pusher_beta_cc02_s2` | RobotAssembler Pusher、制御コスト変更後 |
| `ra15_pusher_beta_cc02` | RobotAssembler Pusher、制御コスト変更後 |

例:

```bash
bash /userdir/StackelbergPPO_ra/scripts/demo_cnoid.sh ra15_pusher_beta_s2
bash /userdir/StackelbergPPO_ra/scripts/demo_cnoid.sh ra15_pusher_beta
bash /userdir/StackelbergPPO_ra/scripts/demo_cnoid.sh ra15_pusher_alpha
bash /userdir/StackelbergPPO_ra/scripts/demo_cnoid.sh ra15_pusher_beta_cc02_s2
```

発表用動画として存在する RobotAssembler Pusher の成果物は次のとおり。

- `demo/ra15_pusher_beta_s2.mp4`
- `demo/ra15_pusher_beta.mp4`
- `demo/ra15_pusher_alpha.mp4`
- `demo/ra15_pusher_alpha_s2.mp4`
- `demo/ra15_pusher_beta_cc02_s2.mp4`

## RobotAssembler Target-Pusher

完走済み run は存在する。

- `ra15_tp_beta`
- `ra15_tp_beta_s2`
- `ra15_tp_rate_beta`
- `ra15_tp_rate_beta_s2`
- `ra15_tp_rate_beta_s3`
- `ra15_tp_rate_beta_ext400`

結果の良い代表例として記録されているのは `ra15_tp_rate_beta_s3` である（系譜 9-345、目視記録）。

現在の `demo_cnoid.sh` には RobotAssembler Target-Pusher 用の表示設定がない。完走済み run の代表例は `ra15_tp_rate_beta_s3` だが、実物メッシュ・カメラ・目標表示を確認してから対応する。

## 注意

- 画面デモは `VIEWER_RESTORE_DIR=single_run/<run>` と `VIEWER_EPOCH=best` で checkpoint を復元する。
- 9-236 以降の run は `launch_env.json` から学習時の物理環境を読む。
- RobotAssembler 版は worktree 側にしかない XML・メッシュがあるため、main から起動しない。
- 目視記録のある run と、発表用動画に使った run は必ず区別する。
